# Review: packages/shared/src (v1)

Opseg: svi moduli + testovi. Stanje: `tsc --noEmit` čist, 170/170 testova prolazi. Nema `TODO`, `console.*`, `any`.

## Šta je dobro

- Kritična matematika je čvrsto testirana protiv Daniels tabela (`vdot.test.ts:24-33`, `predict.test.ts:28-34`) i round-trip testova.
- Plan-generator ima jake invarijante: pokrivenost dana, poravnanje po danu trke, cap rasta, cutback, taper (`plan-generator.test.ts`).
- Moduli su čiste funkcije bez I/O; mrežni pozivi primaju injektiran `fetchFn` (`weather.ts:135-162`).
- ICS implementacija je pažljiva: UTF-8 foldovanje preko `TextEncoder`, CRLF, escape, DTSTAMP (`ics.ts:33-95`).
- Dosledan `LocalizedText` key pattern u explain/coach/guided/fueling/raceday.
- Ulazne provere postoje u vdot/predict/raceday (`assertPositive`), a `schemas.ts` validira datume (Feb 31, lat/lon, RPE).
- `buildPacePlan` tačno čuva ciljno vreme posle zaokruživanja (`raceday.ts:66-69`).

## Top 5 prioriteta

1. **predict.ts:26-31** — detektovati nekorektan opseg pretrage i baciti grešku; tiho saturiranje kvari prognoze za realne početnike.
2. **predict.ts:77** — suziti toleranciju PB detekcije; 21 km long run se već sada lažno prijavljuje kao HM PB.
3. **Zajednički `dates.ts`** — ukloniti 5× kopirane date helpere pre nego što se doda još modula (achievements, sync).
4. **Jedan izvor run tipova + runtime validacija `PlanConfig`** — sprečava tihe greške pri rastu feature seta.
5. **Preciznost distance_km** — kvantizacija na 2 decimale (ili `numeric(6,3)`) + round-trip test; potvrditi da je stvarni tip `numeric(6,2)`, ne `(4,2)`.
