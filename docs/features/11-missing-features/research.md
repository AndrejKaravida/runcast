## Ključne činjenice (verifikovano)

- **iOS web push**: iOS 16.4+ radi samo za sajt dodat na Home Screen (manifest `display: standalone`/`fullscreen`), dozvola
  isključivo posle tapa; u Safari tabu `Notification` ne postoji. iOS 18.4+ declarative web push (`window.pushManager`,
  prikaz bez SW), ali server i dalje šalje (VAPID); APNs endpointi `*.push.apple.com`. Safari oduzima dozvolu ako push
  ne rezultuje vidljivom notifikacijom. (Apple „Sending web push notifications", WebKit blog 16535/16574, OpenPWA)
- **Strava API 2026**: Standard tier traži aktivnu Strava pretplatu developera; 1 athlete podrazumevano → 10 self-service,
  review za više; posrednici zabranjeni; club endpointi uklonjeni 1.9.2026; novi base URL 4.1.2027. (Strava API FAQ/changelog, Sahha)
- **Runna „adaptacija"**: tempi se menjaju preko Pace Insights predloga koje korisnik prihvata, ili ručno (15–30 s);
  Runna svesno ne trenira ka goal time-u. (support.runna.com: „Adjusting Your Estimated Race Time", „Pace Insights")
- **sRPE**: load = RPE × min; ACWR = 7 d / 28 d (uncoupled varijanta), „sweet spot" 0.8–1.3 (Gabbett; Lolli). Bez HR-a
  najbolja zamena, i poklapa se sa RPE drift logikom koju coach već koristi. (RunCalc, AI Running, NorthLine)
- **Treadmill**: 1% pravilo tačno ~7:00–9:30/mi (Jones & Doust 1996); preciznije ACSM + visina/težina — oba polja su u profilu.
- **Share kartice**: canvas render + Web Share API (fajlovi) — bez baze; Strava/Runna tokove pokriva auto-upload slika.
- **Offline/PWA**: `vite-plugin-pwa` (Workbox) daje manifest + SW; SW nije uslov za install (web.dev kriterijumi: HTTPS + manifest + ikone).

## Šta NE gradimo sada (i zašto)

- **Apple Health / Google Fit** — nemoguće iz web app-a (HealthKit nije u Safari-ju; Health Connect je on-device); eventualno iOS Shortcut → webhook, ne sada.
- **Strava full sync** — L obim + gated API (pretplata, review, pravila keširanja/prikaza); eventualno kasnije samo „post to Strava" izvoz.
- **Clubs/izazovi** — prazan feed bez mase; preklapa se sa 10 (leaderboard/profil).
- **Route suggestions** — nova dep + tuđi API ključevi; RunCast je planer, ne navigacija.
- **Podcast audio** — sadržaj/ops, ne kod; TTS guided run je već zamena.
- **Weekly recap email** — email infra (Resend) i deliverability za potrebu koju push (#3) rešava bolje.
