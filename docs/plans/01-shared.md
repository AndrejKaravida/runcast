# 01 — `@runcast/shared` audit (VDOT, plan generator, weather, schemas)

Applying rules: SEARCH, REUSE, NO_ASSUMPTIONS, CHALLENGE. Read-only audit; no `app/`, `packages/` or `supabase/` file was modified (only this file created). Evidence: source + tests read in full, 48/48 tests pass, and edge cases executed against the real code through `vitest` from a temp directory.

## Summary

**Good:** `vdotFromPerformance` matches published Daniels anchors (5K 20:00 → **49.8**, 10K 45:00 → **45.3**, HM 1:45:00 → **42.6**, M 3:30:00 → **44.6**; 5K 25:00 → 38.3 as PLAN.md says). Date math is UTC epoch arithmetic → month/DST safe; `addDays`/`dayDiff`/`weekdayOf` are correct. WMO storm check `code >= 95` is correct (95/96/99, hail included per Open-Meteo/WMO). `windGustKmh` naming is consistent everywhere (no guess/gust typo). BUILD parity (TEMPO + INTERVALS/REPETITIONS alternating), 32% long-run share, 28/32 km caps, race-week 3 km easy minimum, and 0.98 (I) / 1.07 (R) zone multipliers all check out. Pure functions, injectable `fetch`, single zod-v3 dependency.

**Risky:** two P0 calendar bugs in `plan-generator` (weekday mapping; phantom week when `raceDate − startDate` is a multiple of 7) — verified to place long runs on the wrong weekday for any non-Monday start (the app always starts "today") and, worst case, a ~15 km long run 2 days before the race. `pacesFromVdot` applies Daniels' fractions to velocity, not VO₂, so easy/M/T paces are 10–60 s/km too slow (P1). `pickSwapCandidate` can move a workout into the past and can move a RACE (P1). RACE handling in `weather-rules` is incomplete (AIR/COLD → "swap"). Anchors are silently dropped when < 12 weeks remain and `PlanAnchor.kind` is never used (goal = race). All zod schemas and their input types are dead code in v1 (P2).

## Ordered implementation checklist

**1. Fix weekday mapping (P0).** In `buildWeek`, compute `const dow = (weekdayOf(params.weekStart) + day) % 7` and compare `dow` against `layout.longRunDay/qualityDays/easyDays`. Acceptance: for every start weekday × longRunDay, every non-race LONG falls on `longRunDay`; no quality on `longRunDay` or the day after; existing Monday-start tests unchanged.

**2. Fix race-week anchoring (P0).** Last week = `raceDate−6 … raceDate`; `weekIndex` counted back from `raceDate`; `weeks = Math.floor(days/7)+1`; never emit `date < startDate`; race-week layout applies to that week. Acceptance: for race on Mon–Sun, no LONG within 6 days of race; every date from `startDate` to `raceDate` covered exactly once; `raceDate − startDate = 126` → `weeks = 18`; existing tests updated accordingly.

**3. Fix `pickSwapCandidate` (P1).** Add `status` to the target, return `null` for non-`PLANNED`/`RACE` targets, filter `candidate.date >= target.date`, and accept a plan `weekStart`. Update `TodayPage` to pass status + plan-week range. Acceptance: target Wed picks Thu, never Tue; RACE/DONE target → `null`; no cross-plan-week candidate.

**4. Fix weather rule typing (P1).** RACE → `warn`/`keep` (or `earlier` for HEAT) for AIR/COLD/WIND; REST → `info`/`keep`. Acceptance: verified outputs for RACE + AIR/COLD/HEAT/STORM and REST + STORM; no `swap` suggestion for RACE/REST.

**5. Recalibrate zone paces (P1).** In `pacesFromVdot`, derive E/M/T from fraction-of-VDOT inversion (`vdotVelocityMetersPerMinute(frac*vdot)`), keep I/R velocity fractions. Acceptance: VDOT 38/44/50 paces within ±5 s/km of published E/M/T/I/R tables; ordering test still passes.

**6. Anchor handling (P1).** Preserve `anchor` in every branch; use `kind` to cap/label goal paces. Acceptance: 6-week anchored plan returns `anchor != null`; a far-faster goal does not produce paces above `recentVdot + cap`; both `kind`s tested.

**7. P2 batch.** longFinish in PEAK; race-distance parameter; accurate base-plan phase labels; long-run floor; quality-day spacing for longRunDay=5; REPETITIONS reachable for 3–4 days/week or documented; vdot input clamps; schema refinements; weather null/error contracts; wire or delete schema exports. Acceptance: new tests below pass; `npm test`, `npm run typecheck`, `npm run lint` green.
