# Contrast audit (wave 3b)

Audit of semantic text and focus ring color pairs in `app/src/styles/theme.css` for both themes.
Tool: `scripts/check-contrast.mjs` (plain Node, no dependencies). The script parses the CSS custom
properties from the theme file, composites translucent soft tokens over their underlay, and prints
WCAG 2.1 contrast ratios with verdicts. Run it with:

```bash
node scripts/check-contrast.mjs
```

Exit code is 1 when any text pair fails AA. Current state: 94 pairs, 0 text failures, 3 focus ring
failures (light theme only, documented below).

## Method

- Relative luminance and contrast ratio per WCAG 2.1 (sRGB, 0.03928 linearization threshold).
- Text pairs: `text`, `text-secondary`, `text-muted`, `<tone>-ink` on `bg`, `surface`,
  `surface-elevated`, and on soft tokens (`primary-soft`, `rain-soft`, `success-soft`,
  `warning-soft`, `danger-soft`) composited over `bg` and `surface`.
- Primary/secondary/ghost/danger button text, `on-accent` on `primary`, section labels and captions.
- Non-text: focus ring (`primary/60`) against `bg`, `surface`, `surface-elevated`, threshold 3.0.
- Thresholds: 4.5 normal text, 3.0 large text, 3.0 non-text.

Caption and section label pairs carry information at 11 to 12px, so they are held to the normal
text threshold of 4.5. No 3.0 exemptions are used for them. Large text rows (for example hero
numbers at 24px and above) would qualify for 3.0, but every audited pair already passes 4.5.

## Known limitation: light theme focus ring

`focus-visible:ring-primary/60` composites the brand orange at 60% alpha. On dark backgrounds
that yields 3.10 to 3.43 and passes. On the near white light backgrounds it yields 1.75 to 1.89,
below the 3.0 non-text threshold. A token-only fix would require `--color-primary` around `#8f2c05`
in light theme, which would replace the bright orange primary button with a dark rust fill and
break the brand feel (and force `--color-on-accent` and pressed states to change as well).

The correct fix is a per-theme ring color consumed by the focus utilities (for example a
`--color-ring` token used by the `ring-*` classes). Those utilities live in component files that
are owned by the parallel keyboard/aria wave, so this is left as a documented follow-up rather
than changed here. The dark theme ring was fixed in this wave through the dark `--color-primary`
override.

## E2E coverage

`app/e2e/contrast.spec.ts` loads key pages in both themes and asserts computed style contrast in
the browser (alpha compositing over ancestor backgrounds, same WCAG math):

- `/today`: greeting, weather hero window text, weather hero conditions caption.
- `/settings`: first section label.
- `/settings/account`: danger button label.
- `/leaderboard`: secondary caption of the first leaderboard row.

Each check asserts a ratio of at least 4.5.
